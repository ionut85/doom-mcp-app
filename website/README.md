# Landing page

Static landing page for the project, served at https://doom-mcp.vercel.app (Vercel project `doom-mcp-app`, root directory `website/`).

- `index.html`: the whole page (no build step).
- `img/`: frames rendered headlessly by the engine in this repo (`pnpm play-cli`), Freedoom E1M1.

Preview it locally by opening `index.html` in a browser, or with `npx serve website`.
